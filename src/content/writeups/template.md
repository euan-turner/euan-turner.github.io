This is an example write-up. Replace this file (or add new `.md` files alongside it) to publish your own posts.

## How to add a post

Create a new file in `src/content/writeups/` with the `.md` extension. Add frontmatter at the top:

```
---
title: "Your Post Title"
description: "Optional one-liner shown on the index."
date: "2024-06-01"
tags: ["conference", "NLP"]
draft: false
---
```

Then write your post in plain Markdown below the frontmatter. Push to GitHub and the site rebuilds automatically.
